Ondo 개인정보처리방침

최종 개정일: 2026년 4월 23일. 이 페이지는 앱 내 [프로필 > 개인정보처리방침]에 게시된 방침과 같은 기준으로 작성한 공개본입니다. 앱 내 화면이 항상 최신 전문을 담고 있습니다.

1. 수집하는 개인정보 항목

  • 회원 가입·로그인: 이메일, 이름/닉네임, 프로필 이미지 URL, 인증 제공자 종류 (Apple·Google·Kakao·Naver·이메일). 전화번호 인증을 사용하는 경우 전화번호를 함께 수집합니다.
  • 프로필·맞춤 분석: 생년월일, 출생 시간, 성별, MBTI, 혈액형, 관심 주제, 선택형 페르소나 설정
  • 서비스 이용·결제: 채팅 메시지 내용(텍스트·이미지), 인사이트 생성 요청과 결과, 토큰 잔액, 구독 상태, 스토어 구매 영수증과 거래·상품 식별자 (카드번호 등 금융 정보는 수집하지 않습니다)
  • 단말·로그: 기기 모델명, OS 버전, 앱 버전, 푸시 토큰, 앱 실행·오류 로그, 성능 지표

2. 이용 목적

  • 회원 식별·인증·계정 복구와 고객 문의 대응
  • 캐릭터 채팅과 운세·관계·성향·생활 인사이트 생성 및 개인화
  • 구독·인앱결제 확인과 토큰 지급
  • 푸시 알림 발송(채팅 알림, 서비스 공지)
  • 부정 이용 탐지, 오류 분석, 서비스 품질 개선
  • 법령상 의무 이행과 이용약관 집행

3. 권한 사용 안내

  • 카메라: 사용자가 직접 얼굴 사진을 촬영할 때만 사용합니다.
  • 사진 보관함: 사용자가 직접 선택한 사진만 업로드합니다.
  • 마이크·음성 인식: 음성 입력 기능을 사용할 때만 요청합니다.
  • 알림: 채팅 알림과 서비스 공지 수신에 사용하며 앱 설정에서 끌 수 있습니다.

선택 권한은 해당 기능을 직접 실행할 때만 요청되며, 거부해도 다른 핵심 기능은 계속 이용할 수 있습니다.

4. 제3자 제공 및 처리 위탁

법령에 따른 요청이 있는 경우를 제외하고 이용자 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 서비스 제공을 위해 아래 업체에 일부 처리를 위탁합니다.

  • Supabase Inc.: 데이터베이스, 인증, 서버 기능 호스팅
  • Apple Inc.: iOS 푸시 알림(APNs), App Store 인앱결제 검증, Apple 로그인
  • Google LLC: Android 푸시 발송(FCM), 구글 로그인, Google Play 결제 검증, AdMob 보상형 광고
  • Expo: 푸시 토큰 중계(Expo Push Service)
  • Sentry: 앱 충돌·오류 수집 (메시지 본문과 이메일은 전송하지 않습니다)
  • OpenAI, Google(Gemini), xAI(Grok): 채팅·인사이트 응답 생성을 위한 LLM API
  • Kakao, Naver: 소셜 로그인 제공자

AI 응답 생성 시에는 요청 처리에 필요한 범위에서만 외부 LLM 제공자에게 데이터를 전달합니다. Apple 앱 추적 투명성(ATT) 대상 교차 앱 추적은 수행하지 않으며(NSPrivacyTracking: false), 개인정보를 판매하지 않습니다.

5. 국외 이전

위탁 업체 다수가 해외에 서버를 두고 있어 개인정보가 국외로 이전될 수 있습니다. 이전 항목은 1항에 기재된 정보이고, HTTPS/TLS로 암호화하여 서비스 이용 시점에 전송하며, 주요 이전 국가는 미국, 싱가포르, 일본입니다. 이전을 원하지 않을 경우 서비스 이용이 제한될 수 있습니다.
