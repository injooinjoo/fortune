# 온도 웹 운세 UX 경쟁 검토

- 관찰일: 2026-08-24
- 대상: 실제 공개 웹 화면. 로그인·결제 제출은 하지 않음.
- 원칙: 관찰 사실과 제품 판단을 분리하며, 보이지 않은 기능·가격은 추정하지 않는다.

## 출처와 관찰 사실

### 운세미

- 출처: https://unse.me/ · https://unse.me/horoscope
- 홈 title: `🐴 무료 운세 - 사주풀이 · 타로 · 꿈해몽 · 별자리 운세 | 운세미`
- 홈에는 오늘의운세·사주풀이·타로카드·꿈해몽·궁합·토정비결이 상단 탐색으로 노출됐다.
- 첫 방문 시 무료 오늘의 운세/띠별·별자리 운세, AI 사주풀이·타로·궁합, 꿈해몽 검색을 안내하는 시작 모달이 보였다.
- 별자리 운세 페이지는 12개 별자리 결과를 한 화면에서 탐색할 수 있고, 도움됨/아쉬움 피드백 버튼이 보였다.

### 포스텔러

- 출처: https://forceteller.com/
- 홈 title: `🐴 천기NEW설 포스텔러`

- 각 카드에는 콘텐츠 제목과 조회/반응으로 보이는 수치, 포인트로 보이는 수치가 함께 표시됐다.
- 무료·유료 콘텐츠를 별도 상품 타입으로 나누는 구조와 콘텐츠 중심의 발견 흐름은 확인했지만, 로그인·결제 완료는 검증하지 않았다.

## 온도에 적용한 판단

### 이번 슬라이스에 반영

1. **선택 기준을 먼저 제시**: 목록에서 `지금의 흐름을 가볍게`와 `관계나 마음을 더 깊게`를 구분해 처음 방문자의 선택 부담을 줄인다.
2. **비용을 행동 근처에 유지**: 기존 카탈로그의 실제 `온도 N개`를 보존하고 카드 하단에 `열어보기` 행동을 명시한다. 새 상품·가격은 만들지 않는다.
3. **입력 전에 결과 구성을 설명**: 오늘의 운세는 전체 흐름→애정·재물·일·건강의 구조와 필수/선택 입력을 먼저 안내한다.
4. **결과에서 다음 행동 제공**: 일일 결과 뒤 연애운·재물운·캐릭터 대화로 이어지는 관련 읽기 링크를 제공한다.
5. **불안·확정 예언·가짜 사회적 증거는 사용하지 않음**: 경쟁사의 자극적 카피나 후기 수치를 온도에 복제하지 않는다.

### 후속 P1/P2

- P1: 실제 웹 잔액 조회와 부족 상태의 충전 CTA. 서버 카탈로그·checkout·webhook·entitlement가 준비되기 전에는 결제 버튼을 노출하지 않는다.
- P1: 결과 피드백(도움됨/아쉬움)과 실패 이유를 수집하되, 개인 운세 원문·민감정보를 불필요하게 저장하지 않는다.
- P2: 계정 기반 재방문/이메일 리텐션. 실제 저장·동기화가 구현되기 전에는 `저장된다`고 약속하지 않는다.
- P2: 검색 유입용 공개 결과/콘텐츠는 개인정보 입력 결과와 분리한다.
