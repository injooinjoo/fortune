# 온도 웹 광고 등록

- 대상: `https://zpzg.co.kr`
- 게시자: `pub-2803643717997352` (로그인된 AdSense 계정과 기존 로컬 설정의 일치 확인)
- 사이트 검증: 루트 metadata의 `google-adsense-account`와 `/ads.txt`
- Google의 사이트 승인 상태는 AdSense의 `사이트 > zpzg.co.kr`에서 확인한다.

이 설정은 사이트 소유권 및 광고 판매자 확인용이다. 광고 SDK를 로드하거나 광고 쿠키를 생성하지 않는다. 실제 광고 노출 전에는 Google 사이트 승인, 적용 지역에 맞는 동의 관리, 개인정보처리방침, 광고 단위 설정이 필요하다. 광고 클릭을 유도하거나 QA 과정에서 실제 광고를 클릭하지 않는다.

공식 참조: [사이트 연결](https://support.google.com/adsense/answer/7584263?hl=ko), [ads.txt](https://support.google.com/adsense/answer/12171612?hl=ko), [동의 관리 요구사항](https://support.google.com/adsense/answer/13554020?hl=ko).
