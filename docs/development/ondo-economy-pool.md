# 온도 기본 운세 원가 정책

기본 운세를 광고 보상으로도 자주 이용하고, 장문·이미지 프리미엄에서 수익을 내기 위한 변경이다. 기준 커밋은 `065891460b287f1801f831509584925fdf7ea795`다.

## 구현 계약

- 연애·직업·재물·건강·궁합·타로·바이오리듬을 5→1 온도로 변경한다. 오늘/MBTI 등 기존 1 온도와 프리미엄 12/25/50 가격은 유지한다. 공통 가격 원본에서 웹·RN·Edge가 함께 읽는다.
- 운영 DB에 이미 설정된 Gemini 2.5 Flash-Lite를 기본 텍스트 운세의 상한 모델로 고정한다. DB 기본값·A/B 설정과 장애 대체 경로에서 비싼 모델이 선택되지 않도록 한다. 사용자 연결 키(BYOK)와 프리미엄 모델 설정은 유지한다.
- 오늘의 운세에서 **분야 + 점수 + 종합 조언의 사자성어 + 프롬프트 버전**이 같은 공통 조언을 공유한다. 이름·생일·성별·위치·사용자 ID를 공유 프롬프트/저장소에 넣지 않는다. 점수·개인별 정보·당일 계산은 요청마다 기존 방식으로 조합한다.
- 조합마다 검증된 조언 3개까지 축적하고, 이후에는 DB 결과만 읽는다. 유효 기간은 30일이며 프롬프트 버전 변경 시 재사용하지 않는다. 같은 조합에 요청이 몰리면 DB의 짧은 생성 임대가 한 요청만 모델 호출을 허용한다. 준비 중이거나 DB/모델 장애이면 기존 기본 조언으로 응답한다.
- 과거 결과 전체를 담은 cohort pool은 새 조언 풀에 이관하지 않는다. 오늘의 운세의 기존 전체 결과 공유 경로를 제거한다. 동일 사용자의 재시도 캐시·서버 차감·환불·광고 보상 검증은 유지한다.

## 검증과 배포 순서

검증 완료: RN·웹 TypeScript 검사, 웹 production 빌드, 공통 계약 33개, 웹 단위 26개, Deno 조언 풀·라우팅·fallback·응답 본문 timeout 테스트 16개, RLS 정적 감사. 외부 네트워크가 없는 PostgreSQL 17 컨테이너에서 임계치·임대 만료·권한·TTL SQL 테스트도 통과했다. 16개 요청을 네 번 동시에 실행한 64건의 경합 실험에서 생성 임대는 정확히 3개였고, 풀이 채워진 뒤의 요청은 모두 DB hit였다.

DB 검증은 disposable PostgreSQL 컨테이너에 `anon`, `authenticated`, `service_role` 역할을 만든 뒤 이 migration과 `supabase/tests/daily_advice_pool_test.sql`을 `psql -v ON_ERROR_STOP=1`로 실행한다. 이어서 `python3 supabase/tests/daily_advice_pool_concurrency_test.py <container-name>`으로 실제 동시성을 검증한다. 이 스크립트는 `--network none` 컨테이너만 허용한다.

OpenRouter/직접 Gemini 모두 요청 본문까지 timeout을 적용한다. 오늘의 운세는 호출당 20초, 대체 경로까지 최대 두 번 시도하며 생성 임대는 90초다. 라우터의 shadow/legacy 선택과 기존 provider 예산 가드는 유지한다.

운영 반영 시 **DB migration을 먼저 적용한 뒤 Edge와 웹을 배포**한다. 새 DB가 없는 동안에는 오늘의 운세가 기본 조언으로 응답하며 LLM 비용은 발생하지 않는다. 병합 시 Edge Functions 자동 배포가 실행되므로 DB 선행 적용을 생략하지 않는다. 공통 LLM factory와 가격표를 가져오는 다른 Edge Functions도 배포 대상이다. 원복은 이전 앱/Edge 커밋으로 되돌리고 새 private pool은 유지해도 된다. 기존 네이티브 바이너리는 5온도 표시가 남을 수 있으나 새 서버는 1온도를 차감한다. 이번 변경만으로 기기에 새 RN 번들이 설치되지는 않는다.

수동 화면 확인: 미리보기 `/운세`에서 오늘·타로·연애·궁합·재물·직업은 1온도, 사주는 12온도인지 확인한다. 오늘의 운세 입력·실패 재시도·결과 재입력은 기존 경로를 유지한다. 운영 DB migration/Edge 배포/웹 production 반영은 이 가격·저장 정책에 대한 사용자 최종 승인 대상이다.

## 근거와 범위

2026-09-07 운영 DB: 기본/오늘/연애/직업/재물/건강/타로/MBTI는 `openrouter/google/gemini-2.5-flash-lite`다. 따라서 절감 효과는 주로 API 호출 감소에서 발생한다. 로컬 Gemini 테스트 키는 HTTP 400으로 인증되지 않아 실제 모델 품질 비교는 수행하지 못했다.

[Google 공식 가격](https://ai.google.dev/gemini-api/docs/pricing): 2.5 Flash-Lite는 입력 $0.10, 출력 $0.40 / 100만 토큰. [지원 종료 안내](https://ai.google.dev/gemini-api/docs/deprecations)에 따라 종료된 2.0 Flash-Lite 기본 대체값을 2.5로 수정한다. 실현 절감률은 풀 적중률에 따라 달라지며 특정 비율을 보장하지 않는다.

기존 광고 보상 검증은 변경하지 않는다. 웹에는 광고 노출 SDK가 현재 없으므로 이번 원가 변경만으로 웹 광고 수익이 발생하지는 않는다. 광고 네트워크·지면·동의 정책 연결은 이 변경의 범위에 포함하지 않는다.
